# Tiny VLA Teams Paper Draft

This directory contains an arXiv-style LaTeX draft for:

**Tiny VLA Teams: Efficient Multi-Agent Reinforcement Learning for Language-Conditioned Robotic Manipulation**

## Important

This is a complete compileable manuscript draft, not a scientifically complete submission. All values marked `TBD` must be replaced with measured experimental results before upload to arXiv or submission to AAAI.

## Files

- `main.tex` - paper source
- `references.bib` - bibliography
- `build.sh` - build helper

## Build

```bash
./build.sh
```

The script produces `main.pdf` when a LaTeX engine is available.
